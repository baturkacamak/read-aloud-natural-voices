# Dil desteği (i18n)

Uzantıda iki katman vardır:

1. **Çeviri hattı:** JSON kataloglar + `@baturkacamak/localization-toolkit`
   (`l10n.config.json`). Eksik anahtar denetimi, makine çevirisi ve tarayıcı
   tabanlı inceleme arayüzü bu katmanda.
2. **Çalışma zamanı:** `src/i18n.js` + bu hattan üretilen `src/locales/base.js`.
   Temel dil kataloğu her yerde senkron yüklenir; diğer 81 dil seçildiğinde
   `locales/<code>/translation.json` isteğe bağlı olarak yüklenir.

## Dosya düzeni

| Dosya | Rol |
| --- | --- |
| `locales/languages.json` | Temel dil, dil etiketleri ve `ltr`/`rtl` yönü |
| `locales/<code>/translation.json` | **Kaynak of truth.** Düz anahtar → metin kataloğu; diğer diller çalışma anında buradan yüklenir |
| `l10n.config.json` | Localization Toolkit yapılandırması |
| `src/locales/base.js` | **Üretilen.** Temel dil kataloğu + 82 dillik metadata |
| `_locales/<code>/messages.json` | **Üretilen.** Manifest adı/açıklaması/kısayolları |
| `locales/invariants.json` | Makine çevirisine girmeyen marka metinleri |
| `src/i18n.js` | `t()`, dil seçimi, `data-i18n`, canlı güncelleme |
| `.l10n/` | Toolkit'in çeviri hafızası/inceleme durumu (git'e girmez) |

Temel dil **Türkçe**'dir (`baseLanguage: "tr"`). Makine çevirisi Türkçe
metinlerden hedef dile yapılır; mevcut İngilizce çeviriler korunur.

### Çalışma zamanı yükleme

- `src/locales/base.js` yalnızca temel kataloğu ve 82 dillik listeyi taşır;
  her yüzeyde senkron yüklenir (≈31 KB).
- Popup, okuyucu ve service worker uzantı origin'inde olduğu için seçilen dili
  `locales/<code>/translation.json` üzerinden doğrudan `fetch` eder.
- Content script sayfa origin'inde çalıştığı için service worker'a
  `GET_LOCALE` mesajı gönderir; worker kataloğu okuyup önbelleğe alır.
- Katalog yüklenene kadar temel dil gösterilir; yüklendiğinde açık paneller
  `storage`/`notify` akışıyla anında güncellenir.
- RTL dillerinde (`ar`, `fa`, `he`, `prs`, `ps`, `ur`) uzantı sayfalarının
  `dir` değeri metadata'dan uygulanır.

## Komutlar

```bash
npm run locales:build                 # JSON -> src/locales/base.js + _locales
npm run locales:check                 # üretilen dosyalar güncel mi?
npm run l10n:check                    # eksik/fazla anahtar, placeholder, bayat çeviri
npm run l10n:translate -- --languages en           # toplu çeviri + invariant + build
npm run l10n:translate -- --languages en --stale   # sadece kaynağı değişenler
npm run l10n:ui                       # 127.0.0.1:4317 inceleme paneli
npm run l10n:add -- de Deutsch        # yeni dil iskeleti
npm run test:i18n                     # locales:check + birim testleri
```

`l10n:check` deterministik olduğu için CI'da kullanılabilir. `translate` ağ ve
çeviri sağlayıcısı gerektirir. Varsayılan `google-web` deneyseldir ve
`scripts/l10n-translate.mjs` tarafından **toplu** isteklerle kullanılır
(tek tek string yerine `batchSize` kadar metin). Resmî kullanım için
`GOOGLE_TRANSLATE_API_KEY` veya `DEEPL_AUTH_KEY` ile
`--provider google-cloud|deepl` seçilebilir.

`locales/invariants.json` marka adı gibi çevrilmemesi gereken anahtarları
tutar; `l10n:translate` sonunda otomatik uygulanır.

### Yerel LLM ile çeviri

`scripts/l10n-translate.mjs` OpenAI uyumlu yerel bir sunucuyu da kullanabilir
(Ollama, LM Studio, vLLM…):

```bash
L10N_AI_BASE_URL="http://127.0.0.1:11434/v1" \
L10N_AI_MODEL="qwen2.5:7b" \
npm run l10n:translate -- --provider local-ai --languages de
```

- `L10N_AI_BASE_URL`: OpenAI uyumlu `/v1` adresi (Ollama varsayılanı
  `http://127.0.0.1:11434/v1`, LM Studio `http://127.0.0.1:1234/v1`).
- `L10N_AI_MODEL`: model adı. Boş bırakılırsa `/v1/models` listesindeki ilk
  model kullanılır.
- `L10N_AI_API_KEY`: gerekmiyorsa `local` kalabilir.
- `L10N_AI_BATCH_SIZE`: istek başına string sayısı (varsayılan 20).
- `L10N_AI_TIMEOUT_MS`: istek zaman aşımı (varsayılan 180000).

Sağlayıcı, `{{...}}` ve toolkit'in `⟦L10Nn⟧` token'larını korumak için modele
açık talimat verir; dönen JSON dizisi uzunluk/placeholder açısından doğrulanır.
Yerel model yoksa `local-ai` çağrısı anlaşılır bir hata verir.

Bu makinede Ollama kullanıcı dizinine kuruldu ve systemd kullanıcı servisi
olarak etkinleştirildi:

```bash
systemctl --user status ollama
ollama list                 # gemma3:4b
```

Kurulum dizini `~/.local/opt/ollama`, modeller
`~/.local/share/ollama/models`. Yeniden başlatmada servis otomatik açılır;
durdurmak için `systemctl --user stop ollama`.

> Not: 4B yerel model Amharic gibi düşük kaynaklı dillerde yetersiz kaldı.
> Bu yüzden 82 dilin tamamı Google toplu çevirisiyle dolduruldu; yerel model
> ileride seçili dilleri iyileştirmek için kullanılabilir.

## Yeni dil ekleme

Uzantı şu anda `youtube-comment-navigator-95` ile aynı 82 dili destekler.
Yeni bir dil eklemek iki komuttan oluşur:

1. `npm run l10n:add -- de Deutsch`
   - `locales/de/translation.json` (`{}`) oluşturur.
   - `locales/languages.json` içine `{ "label": "Deutsch", "dir": "ltr" }` ekler.
2. `npm run l10n:translate -- --languages de`
   - Eksik anahtarları temel Türkçe katalogdan çevirir.
   - Marka metinlerini uygular (`locales/invariants.json`).
   - `src/locales/base.js` ve `_locales/de/messages.json` dosyalarını üretir.

Manifest, popup, reader veya background dosyalarında **değişiklik gerekmez**;
dil, ayarlardaki **Arayüz dili** listesine otomatik eklenir (Davranış sekmesi).
RTL dilleri `languages.json` içindeki `dir: "rtl"` ile işaretlenir.

Bölgeli diller için küçük harfli BCP 47 kodu kullanın: `pt-br`, `zh-cn`.
Chrome `_locales` klasörü üretilirken alt çizgiye çevrilir (`pt_BR`).

## Çeviri kullanımı

```js
// JavaScript
SesliOkuI18n.t("popup.readPage");                    // "Sayfayı oku"
SesliOkuI18n.t("settings.timer.remaining", { minutes: 12 });
                                                     // "Kalan: 12 dakika"
await SesliOkuI18n.setLocale("en");                  // kalıcı olarak değiştirir
SesliOkuI18n.locale();                               // "en"
```

```html
<!-- Statik HTML -->
<button data-i18n="popup.readPage">Sayfayı oku</button>
<button data-i18n-title="player.prev" title="Önceki paragraf">⏮</button>
<input data-i18n-placeholder="settings.profilePlaceholder" placeholder="Profil adı">
<section data-i18n-aria-label="settings.title" aria-label="Okuma ayarları"></section>
```

- `data-i18n` → `textContent`
- `data-i18n-title` → `title`
- `data-i18n-aria-label` → `aria-label`
- `data-i18n-placeholder` → `placeholder`

`data-i18n` düğümünün içeriği tamamen değiştirilir. İçinde başka elemanlar
(select, ikon, `<kbd>`) varsa çevrilecek metni ayrı bir `<span data-i18n>`
içine alın.

Dinamik arayüzlerde kökü bir kez kaydedin; dil değişince metinler yenilenir:

```js
const release = SesliOkuI18n.observe(shadowRoot);
// dispose içinde: release();
```

Sözlükte bulunmayan anahtar önce temel dile, o da yoksa anahtarın kendisine
düşer.

### Placeholder biçimi

Yer tutucular **çift süslü parantez** ile yazılır:

```json
"settings.timer.remaining": "Kalan: {{minutes}} dakika"
"settings.timer.remaining": "Remaining: {{minutes}} min"
```

Toolkit bu tokenları çeviriden korur ve iki dilde aynı olduğunu doğrular.
Yeni anahtar eklerken önce `locales/tr/translation.json` (temel) dosyasına
ekleyin, sonra `npm run l10n:translate -- --languages en` çalıştırın.

## Manifest yerelleştirmesi

Manifest metinleri aynı katalogda `manifest.*` anahtarlarıyla tutulur:

- `manifest.appName`, `manifest.appDescription`, `manifest.actionTitle`
- `manifest.commandReadPage` vb.

`locales/invariants.json` içindeki `app.name` marka adının tek kaynağıdır. `npm run locales:build`, bu adı tüm kataloglardaki `app.name` alanına uygular. `manifest.appName` yerelleştirilir ve `manifest.actionTitle` bununla eşitlenir. Başlık, yedek uyarısı ve yedek dosyası adında `{{appName}}` ve `{{appSlug}}` otomatik doldurulur.

`locales:build`, bunları 82 dil için `_locales/<code>/messages.json` içine
`appName`, `actionTitle`, `commandReadPage` adlarıyla yazar. `manifest.json` bu adları
`__MSG_*__` ile kullanır. Chrome arayüz dili ile uygulama içi dil seçimi
birbirinden bağımsızdır; manifest her zaman tarayıcı dilini izler.

## Kurulum ve CI

Paket GitHub Packages üzerinden gelir. Repo kökündeki `.npmrc` token'ı ortam
değişkeninden okur:

```bash
NODE_AUTH_TOKEN="$(gh auth token)" npm install
```

`gh` token'ında `read:packages` yetkisi olmalıdır. `l10n check` token
gerektirmez; yalnızca `translate`/`ui` çalışırken sağlayıcı ayarı gerekir.
Çeviri katalogları paketlenir (`locales/`), böylece seçilen dil çalışma anında
indirilebilir.
`.l10n/` klasörü varsayılan olarak `.gitignore` içindedir.

## Çeviri durumu

- **82 dil × 396 anahtar = 32.472 metin** tamamlandı (`l10n check`: 0 eksik,
  0 placeholder hatası, 0 bayat kayıt).
- Uygulama markası sabittir; manifest adı ve araç çubuğu başlığı her dil için yerelleştirilebilir.
- Chrome'un 132 karakter açıklama sınırı için 11 dilde `appDescription`
  kelime sınırında kısaltıldı.
- Google'ın placeholder'ı bozduğu 19 string, İngilizce güvenli değerle

- `zh`, `pt`, `tl`, `yue` için Chrome manifest kodları sırasıyla `zh_CN`,

### Gemini ile çeviri gözden geçirme

`scripts/gemini-review.py`, What If Music Studio'nun ayrı Edge profilindeki Gemini metin işçisini kullanır. Bu projedeki `.venv` ve açık Gemini oturumu gereklidir. Her istekte tek dilin bütün anahtarlarını işler; geçerli sonuçları `.l10n/gemini-review/` altında saklar. Bir dil tamamlandığında katalogları ve üretilen manifestleri günceller. Kaynak veya katalog değişmişse üzerine yazmadan durur. Hatalı cevap `last-invalid.json` dosyasında incelenebilir. Yanıtın doğrulanması anlam doğruluğunu garanti etmez.

```bash
../what-if-music-studio/.venv/bin/python scripts/gemini-review.py --languages es,de
../what-if-music-studio/.venv/bin/python scripts/gemini-review.py
```

Tekrar çalıştırıldığında tamamlanmış ve değişmemiş dilleri atlar, kaydedilmiş gruplardan devam eder. `--max-batches 1` tek istekle deneme yapar. Tarayıcı, oturum, kota veya doğrulama hatasında işlem durur; durumu inceleyip komutu yeniden başlatın. `GEMINI_STUDIO_DIR` ile diğer proje yolu değiştirilebilir.

Kolay başlatma: `./scripts/gemini-ceviri.sh`. Aynı anda iki çalışmayı kilitle engeller. Bir istek gönderilmiş olabilir ama doğrulanamamışsa otomatik tekrar göndermez; Gemini'deki son konuşmayı kontrol ettikten sonra `./scripts/gemini-ceviri.sh --clear-uncertain` ile devam edin. Hatalı JSON durumunda kaydedilen yanıtı inceleyin; tekrar çalıştırmak ilgili isteği yeniden gönderir.

Varsayılan sıra, ana dil ve ikinci dil konuşurları için yaklaşık önceliktir ve `locales/gemini-priority.json` içinde tutulur; kesin bir nüfus sıralaması değildir. Tamamlanmış diller atlanır.

Gemini çeviri yerine ret mesajı veya doğrulanamayan bir yanıt verirse betik o dili uygulamaz; yanıtı `<dil>-invalid.json` olarak saklayıp diğer dillere devam eder. En sonda başarısız dilleri bildirir ve hata koduyla çıkar; yeniden çalıştırıldığında bu diller yeniden denenir. Gönderimin yapılıp yapılmadığı belirsizse betik durmaya devam eder.

Çeviri işçisi önce Pro seçer. Pro model seçicide kullanılamıyorsa veya Gemini açıkça metin kotasının dolduğunu bildirirse aynı hesapta Flash/Fast seçmeyi dener. Ardından işçinin hesap havuzu, uygun ve doğrulanmış diğer hesaplara geçebilir. Belirsiz gönderimler tekrar gönderilmez. Bu davranış yalnızca bu betiğin Python sürecindedir; What If Music Studio iş akışını değiştirmez.
Çeviri çalışması, Studio'nun önceden kaydettiği Pro kota durumları nedeniyle Flash'ı atlamamak için hesap durumlarını süreç içinde ayrı tutar; Studio'nun kalıcı hesap/kota kayıtlarına yazmaz. Hesap seçimi ve oturum doğrulaması yine Studio profilinden gelir.
Gönderim veya yanıt belirsizse Gemini sekmesi inceleme için açık bırakılır. Tarayıcı geçmişinde aynı isteği kontrol etmeden `--clear-uncertain` kullanmayın; bu seçenek isteği tekrar gönderebilir.

Başlatma betiği terminal çıktısını ve Python hata izlerini `.l10n/gemini-review/run.log` dosyasına da ekler; her çalışmanın zamanı ve çıkış kodu kaydedilir. Dosya yalnızca kullanıcıya açık izinlerle oluşturulur. Gönderilen metinler normal günlükte yazılmaz; doğrulanamayan yanıtlar ayrı `*-invalid.json` dosyalarında tutulur.

### Mağaza metinleri

`store-assets/source.json` Türkçe kaynak başlığı, kısa ve uzun açıklamayı tutar. `store-assets/descriptions/<dil>.txt` uzun mağaza açıklamasıdır; başlık ve kısa açıklama `locales/<dil>/translation.json` içindeki manifest anahtarlarından üretilir. `./scripts/gemini-magaza.sh` Gemini ile varsayılan olarak 10 dili bir istekte çevirir; JSON, alanlar ve uzunluklar kontrol edilir. Geçersiz yanıt alan gruplar bölünerek tekrar denenir; tamamlananlar `.l10n/store-translation/completed.json` ile izlenir. Hatalar `.l10n/store-translation/run.log` dosyasındadır. Bu betik mağazaya yükleme yapmaz.

`--languages en,de` ile seçili dilleri ve `--group-size 1` ile tek dilli istekleri kullanabilirsiniz. Gönderim belirsiz kalırsa Gemini sohbetini kontrol etmeden `--clear-uncertain` kullanmayın.

### Chrome Web Store taslak açıklamaları

`python scripts/cws-descriptions.py --url <geliştirici-paneli-edit-adresi>` yerel dosyaları kontrol eder. `--apply` eklendiğinde What If Music Studio'nun Gemini için kullandığı Edge profiline bağlanır, mağazanın dil listesinde bulunan açıklamaları doldurur ve diller arasında dolaşarak doğrular. `--save-draft` verilirse doğrulama sonrası taslağı kaydetmeyi dener; incelemeye göndermez. `--languages tr,en` ile seçili diller işlenebilir. Google oturumu ve ilgili geliştirici hesabına erişim gerekir.

Mağazanın sunmadığı diller atlanır. `yue` Kantonca kataloğu, Geleneksel Çince `zh-TW` seçeneğine otomatik eşlenmez; bu iki dil aynı değildir. Mağaza kodları Google'ın sunduğu seçeneklere göre kontrol edilmelidir. Chrome uyumluluğu için `STORE.md` içindeki Edge ses servisi sınırlamasını yayın öncesi ayrıca test edin.

### Ortak Browser AI servisi

`gemini-ceviri.sh` ve `gemini-magaza.sh` kardeş `browser-ai-automation` deposundaki yerel servisi başlatır veya açık servisi kullanır. Servis, şu aşamada What If Music Studio'nun mevcut metin işçisini arka uç olarak kullanır; Gemini profilindeki hesaplar korunur. Son iş kimliği `.l10n/browser-ai-service/last-request.json` içindedir. Belirsiz gönderim kendiliğinden yeniden gönderilmez. Servis ve Python ortamı için kardeş proje dizinleri gereklidir; servis kökü `BROWSER_AI_ROOT` ile değiştirilebilir.
